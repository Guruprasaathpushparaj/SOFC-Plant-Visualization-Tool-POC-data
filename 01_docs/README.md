# docs — plant reference material

Input documents the analysis is built on. Nothing here is generated by code.

| File | What it is |
|---|---|
| `Flow_diagram.png` | Process flow diagram of the plant |
| `System layout with sensors.png` | Plant layout with every sensor tag marked |
| `operational-modes.md` | **Stage definitions**: what Start-up, Hot standby, Part load, Shut-down … mean and how they are detected in data (the scripts cite its § numbers) |
| `component_sensor_map_en.md` | Which sensor belongs to which component, plus the safety-trip limits (§4) |
| `sofc-operational-stage-literature.md` | How other SOFC makers and standards name their stages |
| `sensors displayed in the visualization tool.xlsx` | Original list of tags shown in the plant's visualization tool (read by `03_data_analysis/excel_sensor_analysis.ipynb`) |
| `sensors displayed in the visualization tool - NEW.xlsx` | Updated version of that list (read by `03_data_analysis/scripts/slopes_jerk.py`) |
| `106 other sensor data_ in relation with the 50 sensors and stages.png` | Chart: how the 106 non-stage sensors relate to the 50 stage sensors |

Code comments like "operational-modes.md §1" point to the files in this folder.
